# Описание интерфейса (День 6)

## Экраны и состояния (3+)
1. **Главный экран (Темная тема)** — отображение дисплея, сетки кнопок, кнопок управления.
2. **Главный экран (Светлая тема)** — переключение цветовой схемы.
3. **Главный экран (Тема Vice City)** — кастомный фон с картинкой и градиентными кнопками.
4. **Диалоговое окно «История»** — отображение списка последних вычислений с возможностью очистки.

## Навигация
- Переключение тем: кнопка «Тема» в правом верхнем углу.
- Просмотр истории: кнопка «История» в правом верхнем углу (вызывает AlertDialog).

## Связь с логикой
- Интерфейс связан с классом `CalculatorEngine` (вычисления) и `HistoryRepository` (сохранение и загрузка из файла `history.txt`).
- Все вычисления проходят валидацию (обработка деления на ноль, пустого ввода).

## Обработка пустых состояний
- Если история пуста, при нажатии на кнопку «История» выводится сообщение «История пуста».
- При пустом поле ввода и нажатии «=» выводится сообщение «Пустое выражение».
