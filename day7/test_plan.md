# Тест-план приложения «Калькулятор»

## 1. Объект тестирования
Мобильное приложение «Калькулятор» на платформе Android (эмулятор Medium Phone API 37.0).

## 2. Что тестируем
- Основные арифметические операции (сложение, вычитание, умножение, деление).
- Обработка скобок и приоритетов операций.
- Обработка ошибок ввода (деление на ноль, пустое выражение, некорректные символы).
- Сохранение и загрузка истории вычислений.
- Переключение тем (Темная, Светлая, Vice City).
- Работа с дробными числами и отрицательными числами.

## 3. Сценарии (Типы тестов)
- **Функциональное тестирование:** проверка правильности расчетов.
- **Тестирование граничных значений:** пустой ввод, очень большие числа, деление на ноль, несколько операторов подряд.
- **UI-тестирование:** корректность отображения кнопок, смена тем, видимость истории.
