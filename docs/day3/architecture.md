# Архитектура приложения «Калькулятор»

## 1. Слои приложения
1. **UI (Интерфейс)** — Activity, XML-разметка (будет реализовано на Дне 6).
2. **Бизнес-логика (Ядро)** — класс `CalculatorEngine`, отвечает за парсинг строки и математические вычисления.
3. **Данные (История)** — локальное хранилище для сохранения последних операций.

## 2. Диаграмма классов
- **CalculatorEngine**
  - `fun calculate(expression: String): Double` — вычисляет результат.
  - `fun formatResult(result: Double): String` — форматирует вывод.

## 3. Диаграмма последовательности (Успешное вычисление)
1. Пользователь нажимает «=».
2. `MainActivity` передает строку (например, "2+2*2") в `CalculatorEngine.calculate()`.
3. `CalculatorEngine` парсит строку, учитывая приоритет операций.
4. Возвращает результат `6.0`.
5. UI отображает результат.

## 4. Диаграмма последовательности (Деление на ноль)
1. Пользователь вводит "5/0".
2. `CalculatorEngine` при вычислении выбрасывает `ArithmeticException("Деление на ноль")`.
3. UI перехватывает ошибку и показывает сообщение пользователю.
