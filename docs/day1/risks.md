# Риски проекта «Мобильный калькулятор»

| № | Риск | Вероятность | Влияние | Меры реагирования |
|---|---|---|---|---|
| 1 | Не успею сделать удобный UI | Средняя | Высокое | Сначала сделать простой рабочий интерфейс, украшения — в конце |
| 2 | Проблемы с сохранением истории | Средняя | Среднее | Использовать простой текстовый формат + резервный вариант через SharedPreferences |
| 3 | Ошибки при парсинге выражений | Высокая | Высокое | Тщательно тестировать граничные случаи, использовать проверенный подход |
| 4 | Неправильное отображение истории | Средняя | Среднее | Ограничить историю 20–30 записями, сделать простой список |
| 5 | Нехватка времени на тестирование | Средняя | Высокое | Писать unit-тесты параллельно с разработкой ядра |
