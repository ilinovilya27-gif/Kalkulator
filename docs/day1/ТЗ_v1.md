# Техническое задание v1
## Мобильное приложение «Калькулятор»

### 1. Цель проекта
Разработать простое мобильное приложение-калькулятор для Android, которое позволяет выполнять основные арифметические операции, сохраняет историю вычислений и корректно обрабатывает ошибки ввода.

### 2. Целевые пользователи
- Студенты и школьники.
- Обычные пользователи, которым нужен быстрый и простой калькулятор без лишних функций.

### 3. Функции

**Must have (обязательно):**
- Выполнение основных операций: сложение, вычитание, умножение, деление.
- Отображение текущего выражения и результата.
- История вычислений (последние 20–30 операций).
- Сохранение истории в локальное хранилище.
- Обработка ошибок: деление на ноль, некорректный ввод, переполнение.
- Кнопка очистки (C / AC).
- Кнопка удаления последнего символа (⌫).

**Should have (желательно):**
- Возможность очистки всей истории.
- Просмотр истории в отдельном экране или нижней панели.
- Сохранение истории между запусками приложения.

**Could have (по возможности):**
- Смена темы (светлая/тёмная).
- Копирование результата в буфер обмена.
- Проценты и смена знака (±).

### 4. Ограничения
- Платформа: Android.
- Язык: Kotlin.
- Минимальная версия SDK: 24 (Android 7.0).
- Хранение данных: локальное (без интернета и без аккаунтов).
- Не требуется авторизация и облачное хранение.

### 5. Критерии приёмки
1. Приложение запускается без ошибок на эмуляторе.
2. Все основные арифметические операции выполняются корректно.
3. При делении на ноль показывается понятное сообщение об ошибке.
4. История вычислений сохраняется и восстанавливается после перезапуска приложения.
5. Интерфейс понятный и удобный для одной руки.
6. Есть обработка некорректного ввода.
