# Руководство пользователя

## 1. Установка и запуск
1. Скачайте файл `app-debug.apk` (или запустите проект в Android Studio).
2. Установите на устройство с Android 7.0 (API 24) и выше.
3. Откройте приложение «Калькулятор».

## 2. Основные экраны
### Главный экран
- **Дисплей (сверху):** отображает введенное выражение и результат.
- **Сетка кнопок:** цифры от 0 до 9, операции (+, -, ×, ÷), скобки, точка.
- **Специальные кнопки:** 
  - `C` — полная очистка экрана.
  - `⌫` — удаление последнего введенного символа.
  - `=` — вычисление результата.
- **Верхняя панель:**
  - Кнопка «Тема» — переключает оформление (Темная -> Светлая).
  - Кнопка «История» — открывает окно с последними 20 вычислениями.

## 3. Основные сценарии
- **Вычисление:** Нажмите `2`, `+`, `2`, `=`. На экране появится `4`.
- **Использование скобок:** Нажмите `(`, `2`, `+`, `2`, `)`, `×`, `2`, `=`. Результат `8`.
- **Просмотр истории:** Нажмите кнопку «История» вверху. В появившемся окне показаны прошлые операции. Чтобы удалить историю, нажмите «Очистить».
- **Продолжение вычислений:** После получения результата (например, `4`), можно сразу нажать `+`, `3` и `=`. Результат будет `7`.

## 4. Обработка ошибок
- Если ввести `5/0`, приложение выдаст сообщение «Деление на ноль».
- Если нажать `=` при пустом экране, появится «Пустое выражение».
